Getting Started

使用方法

从下载技能包到产出第一份底稿，四步走完。全程以 WorkBuddy 为例。

本页目录 一、前置条件 二、安装步骤 三、调用技能 四、完整示例 五、注意事项 六、常见问题
三步速览

方式一：下载 zip → 解压后放进技能目录 → 新开会话； 方式二：复制安装提示词发给 AI 助手 → 新开会话。装完都用一句话描述任务即可调用。

装之前请先装全局制式包 auditox-wp-standard —— 其余技能包都依赖它。

一前置条件

必需

  • WorkBuddy 桌面端 —— 技能运行在 WorkBuddy 里，没有它无法调用。
  • 解压工具（方式一需要）—— Windows / macOS 自带即可；处理中文文件名更稳的话可用 7-Zip。

可选（不影响调用）

  • Excel 或 WPS —— 用来打开技能产出的 .xlsx 底稿工作簿。
  • 夸克网盘客户端（方式一）—— 一次下载多个技能包时更省事；网页版也能下载。
  • 支持 SkillHub 的 AI 助手（方式二）—— WorkBuddy / Claude Code / Cursor 等，需能联网并执行命令。
  • Python 3.9+ —— 只有想跑技能包自带的回归测试时才需要。
技能包之间不是彼此独立的

所有科目技能包都建立在全局制式包 auditox-wp-standard（四段式底稿制式）之上。 只装科目包、不装制式包，编制出的底稿会缺少统一结构。

二安装步骤

两种方式任选其一，装完效果一样：方式一（网盘）手动下载解压，离线也能用； 方式二（对话安装）把一段提示词发给 AI 助手，由它自动装好。技能包详情页两种入口都提供。

方式一 · 网盘安装（手动）

下载 → 解压 → 放进技能目录 → 新开会话，共四步。

  1. 1
    下载技能包

    进入「技能库」，点开要用的科目，在详情页右侧「下载技能包」卡片里点前往下载。 链接指向夸克网盘，公开、永久有效，无需提取码。

    • 先下载 auditox-wp-standard（全局制式包），再下科目包。
    • 文件名即技能包 ID，例如 z-1-2-bank-deposits.zip。
  2. 2
    解压

    解压后应得到一个与 zip 同名的文件夹，里面直接就是 SKILL.md 等文件。

    z-1-2-bank-deposits/ ├─ SKILL.md ← 技能入口，必须在这一层 ├─ dsl.json ├─ CHANGELOG.md ├─ procedures/ ← 程序卡 ├─ templates/ ← 底稿工作簿模板 └─ tests/ ← 黄金用例
  3. 3
    放进技能目录

    把整个技能文件夹放进下面任一个技能目录。二选一，推荐用户级。

    用户级 %USERPROFILE%\.workbuddy-ai\skills\
    macOS / Linux ~/.workbuddy-ai/skills/
    项目级 <项目目录>\.workbuddy-ai\skills\
    • 用户级：所有项目都能用，适合常用科目。
    • 项目级：只在当前项目生效，适合「这个项目才用得上」的科目。

    放好后目录长这样：

    .workbuddy-ai/skills/ ├─ auditox-wp-standard/ ← 全局制式包 ├─ z-1-2-bank-deposits/ ← 科目包 └─ f-1-borrowings/
  4. 4
    新开一个会话

    技能在会话启动时加载。装完后新开一个会话即可识别，不需要重启电脑。

    想确认装好没有，直接问一句：「我现在有哪些可用的审小牛技能？」

方式二 · 对话安装（SkillHub）

不用下载、不用解压。复制一段提示词发给你的 AI 助手，它会读取 SkillHub 的安装规范，自动装好。

  1. 1
    打开技能详情页

    在「技能库」里点开要用的科目。详情页右侧「下载技能包」卡片的下半部分， 就是安装到 AI 助手入口。

  2. 2
    复制安装提示词

    点一下提示词框，整段提示词就复制到剪贴板了。内容形如：

    请根据 https://skillhub.cn/install/skillhub.md，安装 `@org-c491l5hl/z-2-accounts-receivable`。
    • 这段话是给 AI 助手看的指令，不需要你理解，原样复制即可。
  3. 3
    发给你的 AI 助手

    粘贴发送即可。助手会自动完成「装 SkillHub CLI → 下载技能 → 放进技能目录」整套动作。

    • WorkBuddy、Claude Code、Cursor 等支持 SkillHub 的助手都可以。
    • 助手需要能联网并执行命令；沙箱环境可能要先授权联网。
  4. 4
    新开一个会话

    技能在会话启动时加载。装完后新开一个会话即可识别，不需要重启电脑。

部分技能包暂未上架 SkillHub

这类包的详情页会显示「未上架skillhub，请使用网盘下载后安装~」，请改走方式一。

装不上？八成是多套了一层目录

技能目录必须能直接看到 SKILL.md。下面这种多套一层的结构识别不到：

skills/ └─ z-1-2-bank-deposits/ └─ z-1-2-bank-deposits/ ← 多了一层 └─ SKILL.md

三调用技能

方式一 · 自然语言描述任务（推荐）

不用记技能名。直接说清楚科目 + 期间 + 要做什么，技能会被自动匹配：

用 Z-1-2 银行存款技能，做一下 XX 公司 2025 年度银行存款底稿 帮我按 F-1 短期借款技能组，复核这份借款明细表

方式二 · 直接点名调用

知道技能包 ID 时可以直接点名：

调用 z-1-2-bank-deposits

首次调用会看到什么

技能在当前会话中第一次被调用时，回复开头会先完整输出一段《开发者说明与使用说明》 （含开源许可与免责声明）。同一会话内再次调用不会重复；新开会话会重新输出一次。

四完整示例：做一份银行存款底稿

  1. 1
    技能先告诉你需要什么资料

    每个技能包在「六要素」里写明了所需资料。以银行存款为例：

    • 银行存款余额明细表 / 科目余额表
    • 银行对账单（全账户、全期间）
    • 银行存款日记账
    • 已开立银行结算账户清单
    • 银行询证函及回函、余额调节表、定期存单

    资料缺项时技能会先列缺口清单并挂起，不会硬着头皮往下做。

  2. 2
    指定项目工作目录

    技能只在项目目录内读写。原始资料目录（01_原始资料）为只读， 所有产出写入工作底稿目录。

  3. 3
    技能按程序卡分派执行

    技能不会「一口气写完」，而是按依赖顺序逐张程序卡推进：

    P01 余额明细表 ├─→ P02 账户完整性 ├─→ P08 实质性分析程序 ← 与上一张可并行 ├─→ P04 余额调节表检查 ├─→ P06 发生额双向核对 ├─→ P07 截止测试 └─→ P10 披露检查 P03 定期存款 / P05 银行函证 → 标记为人工主导，单独跟踪

    每张程序卡都有明确的输入、输出契约、质量门，算得出来的走确定性工具， 需要判断的会标注「待人工确认」。

  4. 4
    产出四段式底稿

    每份底稿统一四段结构：

    • 一、项目基本信息 —— 被审计单位、期间、编制/审核人、索引号
    • 二、审计目标和程序说明 —— 对应认定与执行程序
    • 三、审计程序执行结果 —— 实测数据与核对结果
    • 四、审计说明 —— 差异原因、结论、待确认事项

    产出两个文件：

    Z-1-2银行存款审计工作簿.xlsx ← 工作簿（含公式与示例行） Z-1-2银行存款审计工作簿+修订记录.md ← 修订记录，与工作簿版本一一对应

五注意事项

数据与合规

  • 别把客户敏感数据传给公开的 AI 服务 —— 这是使用前提，不是建议。
  • 技能只在项目目录内操作，不会向项目目录外发送客户数据。
  • 原始资料目录只读；技能不做物理删除，删除一律移入可恢复区。

出稿纪律

  • 数字核对一律走脚本精确匹配，不允许用模型估算代替。
  • 「待人工确认」不是客套 —— 涉及差异原因、错报认定的结论，未经复核不得进正式底稿。
  • 强制程序不可跳过（如银行函证）。确实不适用，必须记录理由并经人工批准。
  • 不代替人工执行函证寄发、跟函、监盘等需要人到场的动作。

版本与更新

  • 每个技能包自带 CHANGELOG.md，记录该包自身的内容变更（按时间倒序）。
  • 网站技能详情页底部有「更新记录」板块，与包内文件同源。
  • 更新技能包时，用新文件夹整个替换旧文件夹，不要只覆盖单个文件。

适用边界

  • 技能输出仅供学习与工作参考，不构成审计意见或专业建议。
  • 技能是助理级执行者，不替代项目经理的判断与复核责任。
  • 没有对应科目技能包时，可走通用三段式兜底底稿。

六常见问题

装好了，但会话里识别不到技能？
按顺序排查：① 技能目录里是否直接能看到 SKILL.md（多套一层目录会识别不到）； ② 是否新开了会话（技能只在会话启动时加载）； ③ 项目级技能只在对应项目里生效，换项目要放用户级。
夸克网盘链接打不开？
技能库的下载链接都是公开永久链接，正常应可直接打开。如果失效，可以先用方式二（对话安装）顶上； 也欢迎通过「联系」页告诉我，我会尽快补新链接。
安装提示词发给 AI 助手后没反应？
按顺序排查：① 助手是否能联网（沙箱环境常需要先授权网络）； ② 提示词是否整段完整粘贴（含开头的 skillhub.cn 链接，少了它就不知道去读哪份规范）； ③ 助手是否有执行命令的权限。都不行就改走方式一。
对话安装会把技能装到哪个目录？
由你的 AI 助手决定，通常是它自己的技能目录（WorkBuddy 为 ~/.workbuddy-ai/skills/）。 装完可以直接问助手一句「刚装的技能放在哪个目录」，它会告诉你。
为什么有的技能包没有安装提示词？
说明该包暂未上架 SkillHub，详情页会显示「未上架skillhub，请使用网盘下载后安装~」。 这类包请走方式一（网盘），功能和已上架的一样。
可以只装一个科目包吗？
可以，但强烈建议同时装全局制式包 auditox-wp-standard。 它定义四段式底稿制式，其余技能包都依赖它；缺了它，底稿会缺少统一结构。
为什么产出的是 xlsx，而不是直接生成一份文档？
底稿是要能改、能复核、能归档的工作文件。xlsx 保留公式与明细，方便复核人重算验算； 同时每份工作簿都伴随一份「修订记录 .md」，版本一一对应。
技能包更新了，会影响我已有的底稿吗？
不会。技能包只影响之后新做的底稿；已产出的 xlsx 与修订记录是独立文件，不受影响。 更新前可以先看一眼详情页的「更新记录」，了解改了什么。
没有我需要的科目怎么办？
技能库还在按程序库持续补齐（目前 27 个技能组）。暂时没有的科目，可以走通用三段式兜底底稿； 也欢迎通过「联系」页提需求，我会按程序库优先级逐步补上。
装好了？从技能库挑一个科目开始

建议先用 z-1-2-bank-deposits 试手 —— 它是样板包，程序卡、模板、黄金用例最完整。
